# Product

## Register

product

## Users

Me, monitoring my AI trading agent. Single-user context. The primary task is checking the current market regime, auction state, and position status at a glance.

## Product Purpose

A real-time perpetual futures AI agent dashboard. It surfaces market reads (regime, auction, position) so I can verify what the agent sees and intervene when needed. Success means I can trust the read at a glance without digging.

## Brand Personality

Sharp, fast, technical. Not hype, not bank-grade sterile. The interface should feel like a well-tuned instrument — precise, responsive, every pixel has a job.

## Anti-references

- No generic SaaS dashboards (no sidebar nav, no metric card grids, no gradients)
- No trading terminal clones (not Bloomberg/TOS density)
- No dark mode clichés (no green-on-black matrix, no glowing neon accents)

## Design Principles

1. **Read at a glance.** Every widget answers one question. No drilling, no hover-to-see.
2. **Data has hierarchy.** The most important value in each widget is visually first. Secondary data recedes.
3. **Motion serves attention.** Animate only what changes. No decorative transitions.
4. **Typography is the UI.** Weight and size carry meaning. Color is secondary.

## Accessibility & Inclusion

WCAG AA minimum. 4.5:1 body text contrast, keyboard navigation, reduced motion support.
